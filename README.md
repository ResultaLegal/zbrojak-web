# zbrojak-web

Vstupná stránka aplikácie **ZBROJÁK** — trenažéra skúšky odbornej spôsobilosti
na zbrojný preukaz podľa zákona č. 190/2003 Z. z.

Tento repozitár obsahuje výhradne 1 kB HTML shell. Všetky skripty, štýly a dáta
sa načítavajú zo súkromného úložiska; zdrojový kód aplikácie je v samostatnom
privátnom repozitári.

Aplikácia je študijná pomôcka, nie právne poradenstvo. Právne záväzné sú výlučne
znenia uverejnené v Zbierke zákonov SR.
